Bağlantı hakkında

Anahtar HTTPS üzerinden Invoice Control sunucusuna gönderilir ve veritabanında AES-256-GCM ile şifreli saklanır. GitHub Pages'e, tarayıcının yerel depolamasına veya kaynak koduna kaydedilmez.

Kaydedildi ifadesi yalnızca şifreli kaydın başarılı olduğu anlamına gelir; Nutrient API'nin gerçek belge çıkarma işlemini henüz doğrulamaz. İlk gerçek API isteği ücretsiz kullanım kredisi tüketebilir.
