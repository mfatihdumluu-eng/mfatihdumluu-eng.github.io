Bağlantı Açıklaması

Yeşil: Mindee V2 anahtar doğrulaması başarılı. Kırmızı: geçersiz anahtar, erişim hatası, kopuk sunucu veya kontrol edilemeyen bağlantı.

Bu ekran yalnızca bağlantıyı ve anahtar erişimini doğrular; fatura çıkarımı henüz otomatik etkinleşmez. Bunun için Mindee modelinin seçilip belge çıkarma akışına bağlanması gerekir.

API anahtarını app.mindee.com hesabındaki API Keys bölümünden alabilirsin. Bu anahtarı GitHub'a veya herkese açık bir sayfaya yazma.
